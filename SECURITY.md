# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in LicenseLens, please do **not** open a public GitHub issue.

Instead, report it privately by:
1. Opening a GitHub Security Advisory on this repository
2. Or contacting the maintainers directly via GitHub

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 72 hours and aim to release a fix within 7 days of confirmation.

## Scope

The following are in scope:
- Backend API endpoints (`/api/*`)
- File upload and parsing logic
- Authentication and authorization (if applicable)

The following are out of scope:
- Third-party dependencies (report to their maintainers)
- Issues in development-only configurations
