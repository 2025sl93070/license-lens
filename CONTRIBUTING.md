# Contributing to LicenseLens

Thank you for your interest in contributing to LicenseLens.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes with clear, meaningful commits
4. Write or update tests where applicable
5. Open a Pull Request against the `main` branch

## Branch Naming

- `feature/` — new features
- `fix/` — bug fixes
- `docs/` — documentation updates
- `test/` — test additions or fixes

## Pull Request Guidelines

- Each PR should address one issue
- Reference the related issue in the PR description: `Closes #issue-number`
- At least one other member must review and approve before merging
- Do not self-merge without review

## Code Style

- Python: follow PEP 8
- TypeScript/React: follow standard ESLint rules

## Issue Reporting

Use GitHub Issues to report bugs or request features. Use the provided issue templates.

## Code of Conduct

Be respectful and constructive in all interactions.
